# מעטפת הולמת – מעטפת הפרט להורים לילדים עם מוגבלות

אתר סטטי בעברית לעובדות ולעובדי צה״ל. האתר לא דורש שלב בנייה (build). כל הקבצים לפרסום נמצאים בתיקייה `docs/`, וכל הקישורים יחסיים, כך שהאתר עובד גם תחת נתיב משנה של ריפוזיטורי, למשל `https://<user>.github.io/<repo>/`.

## הרצה מקומית

נדרש Node.js 18 ומעלה.

```powershell
node tools/serve.mjs
```

אחר כך פותחים את http://localhost:8080/maatefet-holemet/. השרת מגיש את `docs/` תחת נתיב משנה, כמו GitHub Pages. השרת רושם רק שיטה ונתיב של כל בקשה, כדי שאפשר יהיה לוודא שהטופס לא שולח נתונים.

בדיקות סטטיות (קישורים, עוגנים, קבצים להורדה, סדר כותרות, alt, lang/dir וניגודיות):

```powershell
node tools/check-site.mjs
```

## פרסום ב־GitHub Pages

1. דוחפים את הריפוזיטורי ל־GitHub.
2. ב־Settings › Pages בוחרים Source: **Deploy from a branch**, ענף `main` ותיקייה `/docs`.
3. אחרי כדקה האתר זמין בכתובת `https://<user>.github.io/<repo>/`.

הקובץ `docs/.nojekyll` מונע עיבוד Jekyll. הקובץ `.gitignore` מוציא מהריפוזיטורי את `reference/` ואת `sources-cache/`. האתר מתפרסם רק מ־`docs/`, ולכן חומרי המקור לא נכללים בו. הלוגו, הנספחים הריקים והגופנים הועתקו ל־`docs/`. רשימת אנשי הקשר מעמוד 8 בחוברת מאושרת לפרסום ומופיעה באתר כטקסט.

## איפה מעדכנים

- **תוכן העמודים:** עורכים ישירות את קובצי ה־HTML שב־`docs/`. הכותרת העליונה, הניווט והתחתית חוזרים בכל עמוד. שינוי בהם צריך להיעשות בכל שבעת העמודים. אחרי עריכה מריצים `node tools/check-site.mjs`.
- **דבר השירות הסוציאלי:** האזור `welcome` ב־`docs/index.html`.
- **אנשי הקשר:** הרשימה `contacts` ב־`docs/tmicha.html`. לכל רשומה מעדכנים את התפקיד, השם, המספר המוצג, הקישור `tel:` (בפורמט `+972` בלי האפס הראשון) ואת `aria-label`.
- **צבעים ועיצוב:** `docs/assets/css/site.css`. הצבעים מוגדרים כמשתנים בראש הקובץ.
- **נוסח נספח ג׳ הדיגיטלי:** האובייקט `ANNEX` והפונקציה `buildText` בראש `docs/assets/js/nispach-g.js`, כולל תאריך גרסת הנספח.
- **קובצי הנספחים:** כשיוצא נוסח חדש של הוראה 80‑36, שומרים את ה־PDF החדש בשם `sources-cache/80-36.pdf`. אם מספרי העמודים השתנו, מעדכנים את `PAGES` ב־`tools/split-annexes.mjs`. אחר כך מריצים:
  ```powershell
  npm install
  ```
  ```powershell
  npm run split-annexes
  ```
  כדאי לעדכן גם את מספרי העמודים בקישורים `#page=` ואת תאריך הנוסח בעמודים.
- **טופס 116א׳:** הקישור מפנה לאתר gov.il. בודקים פעם בשנה שהגרסה עדכנית.
